Map key

The map is OpenStreetMap: free, and it works without a key. A Google key adds three things: the detailed map, the station photograph and the 360° view. Kept on the phone in ~/.all.commute/google-api.txt and never shown.

How to get a Google Maps key
  1. Open console.cloud.google.com and sign in with a Google account.
  2. Create a project: the project menu at the top, then New project.
  3. Add billing. Google asks for a card before its maps work. The use of one person normally stays inside Google's free monthly allowance.
  4. APIs and Services, then Library: switch on Maps JavaScript API and Street View Static API.
  5. APIs and Services, then Credentials: Create credentials, API key. Copy the key.
  6. Restrict the key to those APIs, so it is useless for anything else if it ever leaks.
  7. Put the key alone in a text file named google-api.txt, then pick that file with the button above.

Position

Waiting for a fix…
A phone gives its first answer from cell towers and wifi, then tightens as the satellites lock. This listens for 30 seconds and weights each fix by how sure it claims to be, which cancels the random half of the error. It cannot cancel the other half: signal bouncing off the buildings along a street like Ilica arrives late and pushes the fix sideways, confidently. That is why the ring is drawn — it is the phone's own estimate, and standing where two streets open up will do more than any setting here.

Printed timetables

ZET publishes the official vozni red of every line as a PDF. This reads one per line, keeps the times, and throws the PDF away in the same breath — nothing but a small file of times stays on the phone, and it works with no signal at all. When the GTFS feed breaks or the index is a day behind, these fill the holes in the board.

Gemini key

Model for reading timetable PDFs
Needed to read the timetable PDFs. The printed grids are an hour column with loose minutes beside it, in two directions and three day columns — without a key all this can do is scrape stray times it cannot place, and those are never allowed near the board. One call per line, once, then never again.
